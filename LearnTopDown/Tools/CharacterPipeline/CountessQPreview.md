# 암살자 Q 양칼 베기 검증

수련장 `/Game/TopDown/TrainingRoom/Maps/Lvl_DarkTrainingRoom`에서 암살자 Q 연출만 변경한다. 피해 35, 사거리 850cm, 쿨타임 8초, 피해 시점, 이동·복귀·입력 잠금 및 다른 스킬은 보존한다. 숫자 1·2 캐릭터 전환도 유지한다.

현재 기본 표현(3)은 좌우로 짧게 뻗는 직선 칼빛과 독립된 검붉은 파편이다. `Ability_Q`의 좌우 칼 소켓으로 시작 높이와 벌어지는 방향을 확인하되, 휜 경로 전체를 연결하지 않는다. 사용자가 길이와 쨍한 색상을 지적하여, 현재는 원래 약 7.47m 메시의 좌우축만 52%로 줄인 약 3.89m 폭을 사용한다. 피해 범위와는 무관하다. 칼빛 끝은 가늘게 만들고 타격 후 빠르게 지운다. 전용 Unlit Translucent 재질에서 흰색 코어를 낮춘 검붉은 톤을 사용한다. 기존 원본·반월·곡선·밝은 직선 버전의 에셋은 보존한다.

비교용 표현(2)은 `FX_WeaponBase_L/R`, `FX_WeaponTip_L/R`을 120Hz로 평가한 두 칼 궤적이다. 0.10~0.2167초의 칼 밑동·끝을 이어 만든 입체 띠를 가슴 주변 기준 2.6배 확장했다. 실제 궤적 검증은 통과했지만 사용자가 넓은 곡면의 모양을 지적하여, 현재 기본 표현에서는 이 곡면을 사용하지 않는다.

Q 시작 0.10초의 시각 큐에서 생성하고 실제 캐릭터 메시의 위치·회전을 따른다. 재질 UV의 길이 방향은 전개 시각이며 게임 시간에 맞춰 양쪽 칼빛이 펼쳐진다. 도착·피해 이벤트에서 잔상을 월드에 고정하고 이동 궤적·짧은 피격 섬광을 추가한다. 현재 직선 칼빛은 Q 시작 후 약 0.47초에 사라지고 임시 액터도 정리한다. 시전 취소·표적 소실·캐릭터 종료는 별도로 정리한다. 충돌·그림자·내비게이션 영향이나 추가 액터 Tick은 없다.

표현(2)은 원본 궤적을 평가한 결과이고 표현(3)은 원본 소켓을 기준으로 연출을 위해 직선화한 결과다. 실제 칼이 직선으로 움직인다고 주장하지 않는다. 매 프레임 임의의 다른 애니메이션이나 실시간 IK를 다시 평가하는 범용 트레일은 아니다. `Ability_Q` 또는 소켓 정의가 바뀌면 에셋 생성 및 시각 검증을 다시 실행해야 한다. 원본 Paragon 에셋은 수정하지 않는다.

콘솔 `Countess.Skills.QPresentation`: 3은 현재 기본 직선 양칼 베기, 2는 이전 곡선 궤적, 1은 큰 반월 비교용, 0은 기존 원본 표현이다. 기능·화면 검증과 사용자의 미적 승인은 별도로 기록한다.

`Countess.Skills.QTone`은 기본 1(낮춘 검붉은 색), 0(이전 밝은 색)이다. `Countess.Skills.QLengthScale`은 기본 0.52이며 0.35~1 범위에서 표현(3)의 좌우축만 조정한다. 색·길이 비교 시 두 값을 함께 기록한다. `M_CountessQOutwardMuted`는 기존 재질과 색상 수식만 다르며 알파·형태·UV·전개·소멸 수식은 동일하다. 소스 메시를 다시 저장하지 않는다. 현재 생성·비교 도구는 `countess_q_tone_assets.py`, `countess_q_tone_compare.py`, `countess_q_tone_run.py`, `countess_q_tone_review.py`이며 증거는 `Saved/QA/CharacterPipeline/q-tone-cape-20261016`에 저장한다.

현재 생성 도구는 `countess_q_outward_assets.py`, 실제 PIE 비교는 `countess_q_outward_compare.py`와 `countess_q_outward_motion.py`다. 작업 증거는 `Saved/QA/CharacterPipeline/countess-q-outward-20261016`에 저장한다. 아래 기존 궤적 도구·기록은 표현(2)의 이력이다.

## 구현 근거와 재검증

- `CountessSkillComponent.cpp/.h`: Q 전용 시각 큐, 메시 방향 부착, 도착 후 잔상 고정 및 취소 정리. 기존 Q 피해와 타이밍 및 E 코드는 변경하지 않는다.
- `M_CountessQDualSweep`, `SM_CountessQDualSweep`: 프로젝트 소유 신규 재질·메시. 기존 재질·원본 팩·맵은 보존한다.
- `countess_q_blade_probe.py`: 원본 Q의 실제 좌우 칼 소켓과 본 위치를 평가하는 읽기 전용 조사.
- `countess_q_dual_assets.py`: 원본 소켓을 120Hz로 평가해 양쪽 띠를 생성한다. OBJ 가져오기의 Y축 반전을 보정하고 가져온 모든 정점을 원본 계산값과 대조한다. 단순히 저장 성공으로 각도 검증을 대신하지 않는다.
- `countess_q_dual_compare.py`: 실제 PIE 컨트롤러 Q 입력으로 피해·복귀·타격 시간·재질·무충돌·실제 메시와 효과 회전 일치를 확인한다. 같은 조건에서 E의 단일 45 피해를 재확인한다.
- `countess_q_dual_motion.py`: 이전 반월·원본·양칼 표현을 같은 수련장 카메라에서 50ms 간격으로 캡처한다. 다른 방향 시전, 숫자 2 전환, 피해 전 표적 소실의 잔상 정리도 확인한다.
- `countess_q_run.py`, `editor_task.py`: 별도 숨김 오프스크린 에디터로 실행하고 실제 모듈·엔진 종료 코드·재질 컴파일 로그·보호 파일 해시를 확인한다.

단계 비교판과 샘플 GIF는 원본 PIE PNG로 만든다. GIF는 시뮬레이션 간격에 맞춘 화면 샘플이며 연속 영상 녹화가 아니다. 플레이 카메라 확대나 OS 입력 점유는 하지 않는다. 30·60fps는 고정 시뮬레이션 검증이며 GPU 성능 벤치마크가 아니다. QA 프로세스의 캐시 설정은 프로젝트에 저장하지 않는다.
